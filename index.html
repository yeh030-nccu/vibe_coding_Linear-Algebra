核心概念01 / 05

向量不是一個箭頭，
而是一種「位移」

把平面想成由兩個基本方向鋪成的空間。紅色的 î 往右一步，綠色的 ĵ 往上一步；所有平面上的向量，都可以由這兩個方向伸縮、相加而成。

\(\vec{v}=a\hat{i}+b\hat{j}\)

怎麼讀這張圖？

  • a 是向右（或向左）的步數，對應紅色基底 î。
  • b 是向上（或向下）的步數，對應綠色基底 ĵ。
  • 藍色向量的終點座標，正好就是它的兩個係數。
記住這件事

選好一組基底，就等於選好描述空間的語言；向量的座標是它在這組語言中的說法。

核心概念02 / 05

矩陣不是算術表格，
它是空間的「動詞」

把矩陣乘上一個向量，可以想成讓空間中的每個點同時執行同一個動作：旋轉、拉伸、鏡射或剪切。不是只有一支箭頭變了，而是整張網格一起變形。

\(A\vec{x}=\begin{bmatrix}a&b\\c&d\end{bmatrix}\begin{bmatrix}x\\y\end{bmatrix}\)

看懂四個數字

  • 第一欄 (a, c) 是 î 變換後的位置。
  • 第二欄 (b, d) 是 ĵ 變換後的位置。
  • 只要知道兩個基底去了哪裡，就知道整個平面去了哪裡。
觀察重點

動畫開始時，網格是原本的空間；結束後，每一個點都依照同一個矩陣抵達新位置。

核心概念03 / 05

行列式是在問：
空間被放大幾倍？

想像一個邊長為 1 的正方形。矩陣把它送到右側的平行四邊形，而這個新圖形的有向面積，就是行列式。正負號額外記錄了空間是否翻面。

\(\det(A)=ad-bc\)

三種關鍵情況

  • det > 1：面積被放大，方向保留。
  • 0 < det < 1：面積被壓縮，但仍是平面。
  • det = 0：正方形塌成線或點，無法逆轉。
為什麼重要？

det(A) = 0 不只是數字變成零，而是代表兩個新基底失去獨立性；整個平面被壓到較低維度。

核心概念04 / 05

Ax = b：
逆著變換走回去

矩陣 A 把原始向量 x 送到了 b。現在反過來問：哪一個 x 會被送到這個目標？這就是解線性方程組，也就是使用逆矩陣把變換「倒帶」。

\(\vec{x}=A^{-1}\vec{b}\quad\Longleftrightarrow\quad A\vec{x}=\vec{b}\)

畫布上的角色

  • 黃色 b 是已知的終點；它是我們要抵達的位置。
  • 藍色 x 是解；經過 A 後，會精準對上 b。
  • 逆變換動畫會把 b 沿著 A⁻¹ 拉回 x。
唯一解的條件

只有當 det(A) ≠ 0 時，A⁻¹ 才存在；此時每個目標 b 都有唯一的原始向量 x。

b / 目標x / 解A x

核心概念05 / 05

有些方向很特別：
它們只會變長或變短

一般向量經過矩陣後，方向和長度都可能改變；但特徵向量是例外。它們落在一條「不轉彎」的特殊方向上，矩陣只負責把它乘上一個倍率。

\(A\vec{v}=\lambda\vec{v}\)

如何在圖上辨認？

  • 紫色直線是矩陣的特徵方向，正反兩端代表同一條方向。
  • 橘色是你正在測試的向量；藍色是它變換後的結果。
  • 兩者重合時，對齊誤差接近 0°，右側會顯示 λ。
直覺總結

特徵向量是線性變換的「骨架方向」；了解它們，就能預測變換最自然的伸縮方式。
